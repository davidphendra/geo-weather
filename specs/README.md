# Specs

All planning, scope, architecture, and verification documents for the Weather app.

| Path | Purpose |
|------|---------|
| `state.yaml` | Session cockpit: active epic/story, handoff, workflow mode |
| `release-plan.yaml` | WSJF-ordered epic index |
| `execution-status.yaml` | Flat story status store |
| `planning-status.yaml` | Discover-phase checklist |
| `product/SCOPE_LATEST.yaml` | Bounded PRD (what and why) |
| `product/VISION_LATEST.yaml` | North star |
| `product/GLOSSARY_LATEST.yaml` | Ubiquitous language |
| `tech-architecture/` | Stack, test plan, security plan, design plan |
| `adr/` | Architecture decision records |
| `epics/eNN-*/` | Epic capsules (manifest + story specs + task checklists) |
| `bugs/registry.yaml` | Defect registry |
| `verifications/` | Evidence produced by verify-work |
