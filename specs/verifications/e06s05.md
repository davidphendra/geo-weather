## Two defects the harness found (both fixed)
1. **Stale compiled CSS.** `wwwroot/app.css` had not been rebuilt after e06s03/e06s04, so `bg-primary`,
   `bg-secondary`, `bg-surface-container-low`, `text-error` and `bg-error-container` were absent and the
   new pages rendered partially unstyled (transparent buttons). Rebuilt via `npm run build:css`
   (8,994 B → 18,216 B). This is exactly what the optional CI drift guard would catch.
2. **`'strict-dynamic'` broke the Blazor circuit.** Under enforcement, the browser refused
   `ReconnectModal.<hash>.razor.js`: Blazor emits colocated `.razor.js` module scripts as `<script src>`
   without a nonce, and `'strict-dynamic'` disables host allowlisting. The policy now uses
   `script-src 'self' 'nonce-…'` (no `'strict-dynamic'`); the nonce still authorises the inline
   `ImportMap`. Policy unit/integration tests updated.
