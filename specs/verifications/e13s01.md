## What changed

- `Weather.Modules.Favorites.*` renamed to `Weather.Modules.Journal.*` (4 assemblies + test project).
- `Weather.Modules.Notes.*` absorbed into Journal; Notes assemblies and test project removed.
- One `JournalContext` over `journal.db` owning `FavoriteCities`, `WeatherNotes`, `CityProjections`;
  rebaselined migration `CreateJournalSchema`.
- One `City` projection (with coordinate) and one `CityAddedIntegrationEventHandler`.
- Two contracts retained (`IFavoritesService`, `INotesModule`); two controller classes under
  `Weather.WebUI/Api/Modules/Journal/`; routes unchanged.
- Kept `notes.*` / `favorites.*` instruments; module tag is now `Journal`.
- `favorites.db` / `notes.db` retired (no data migration).
- Docs: ADR-0016, CONVENTIONS, AGENTS, SCOPE, GLOSSARY, modules.map, release-plan, state, execution-status,
  tech-stack, DESIGN_PLAN, TEST_PLAN, OBSERVABILITY_PLAN; e13 capsule added.
