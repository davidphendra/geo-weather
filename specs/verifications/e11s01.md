## Notes
- SQLite creates a file but not its parent directory; the host creates `App_Data` before migrations run.
- `App_Data` must be treated as persistent writable storage in deployment (mounted volume / Azure App Service
  `%HOME%\site`); it is safe precisely because it is **not** `wwwroot`.
