## What was built
- `/` (`WeatherExplorer.razor`, `@rendermode InteractiveServer`) replaces the `Home.razor` placeholder and
  consumes `WeatherExplorerModel`.
- `QueryControllerPanel` — CQRS pipeline chips, country/city selects, Fetch Query button.
- `MediatRExpressionBar` — the CQRS expression rail for the selected city.
- `StationHeroCard` + `DiagnosticMetricGrid`/`DiagnosticCell` — hero temperature/condition and the
  diagnostic quad-grid with the D3 substitutions: **visibility** replaces UV/solar, **cardinal** replaces
  gusts, **observed-at** replaces the pressure trend; no fabricated 24h sparkline.
- `ForecastStrip` — the design's strip with an explicit "Forecast not available — current conditions only".
- `CommandDispatchForm` — one form with a **Favorite ⇄ Note** intent toggle (default Favorite) that calls
  the matching endpoint; `ChangeTrackerResponseWell` renders the real HTTP status + response JSON.
- `ArchitectureDeepDive` — cURL / C# tabs with the real route paths.
- `ProblemBanner` — RFC 9457 error surface reused by the page and the response well.
- `CommandDispatchModel` (`MutationIntent`, `CommandOutcome`) — dispatch logic extracted for offline tests.
- Client hardening: a network failure (`HttpRequestException`) is wrapped as
  `WeatherApiException` with `DEPENDENCY_UNAVAILABLE`.
