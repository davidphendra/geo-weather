## Revision after task 7 (real defect)
Task 7 (circuit under enforcement, run by the e06s05 Playwright harness) found that
**`'strict-dynamic'` blocked Blazor's colocated `.razor.js` module scripts** — the framework emits them as
`<script src>` without a nonce, and `'strict-dynamic'` disables host allowlisting:

```
Refused to load the script '…/ReconnectModal.<hash>.razor.js' because it violates
"script-src-elem 'self' 'nonce-…' 'strict-dynamic'". Note that 'strict-dynamic' is present,
so host-based allowlisting is disabled.
```

The policy now uses `script-src 'self' 'nonce-…'` (and `script-src-elem` likewise) with **no**
`'strict-dynamic'`. The nonce still authorises the inline `ImportMap`, and `script-src-attr 'none'` still
forbids inline event handlers. Policy unit and integration tests were updated accordingly.
