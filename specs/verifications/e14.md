## Deviations / notes

- **e14s02 task 4 (metrics):** instruments `weather.forecast.requests` / `weather.forecast.duration` are
  *defined* in `WeatherMeters` (BuildingBlocks) in s02; *emission* (and its test) lives in
  `GetWeatherForecastQueryHandler` (s03), mirroring the existing `weather.report.*` pattern. The s02 task verify
  was narrowed to the BuildingBlocks build; the plan file records this.
- **Header label:** the prototype's fabricated "NWP Model: GFS-0.25°" was replaced with the honest
  `Source: OpenWeather 5d/3h` (ADR-0017).
- **Provider adapter refactor:** `OpenWeatherMapService` extracted a shared `GetPayloadAsync<T>` helper so
  current + forecast share the key handler, resilience, metrics, and 404/failure semantics. Existing
  `OpenWeatherMapServiceTests` / observability tests stay green.
- No new packages; no new configuration; no new secret.
